# Mi Tesis en Progreso

Este repositorio es mi cuaderno abierto de trabajo. Aquí voy guardando lo que aprendo, las dudas que voy resolviendo y las ideas que van surgiendo mientras desarrollo mi tesis.  
Los textos están organizados por carpetas y numerados para mantener un orden cronológico y temático.

## Propósito

- Documentar mi proceso de investigación y escritura de manera transparente.  
- Tener un registro vivo de cómo evoluciona mi pensamiento y mis soluciones.  
- Convertir todo este material en un documento académico final en PDF, que preparo en local con LaTeX.  

## Nota personal

Este repositorio es mi forma de mantenerme organizado.  
Al final, todo lo que está aquí se transformará en la tesis oficial, pero mientras tanto es mi diario de investigación y aprendizaje.
